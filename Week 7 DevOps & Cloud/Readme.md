# Week 7 – DevOps & Cloud

## Overview

This repository contains the learning resources and study materials prepared as part of the **Cognizant Digital Nurture 5.0 – Deep Skilling Program (Java Full Stack Engineer Track)** for **Week 7 – DevOps & Cloud**.

Unlike previous weeks that focused on implementation-based hands-on exercises, Week 7 emphasizes understanding the core concepts of **DevOps, Cloud Computing, Containerization, Continuous Integration & Continuous Deployment (CI/CD), and Generative Artificial Intelligence**.

To support these learning objectives, comprehensive and professionally structured PDF notes have been prepared covering the essential concepts, architectures, workflows, best practices, and industry applications of each topic.

---

## Learning Objectives

By completing the Week 7 learning modules, the following concepts were studied:

- Understand the fundamentals of Docker and containerization.
- Learn the principles and culture of DevOps.
- Explore Continuous Integration (CI) and Continuous Delivery/Deployment (CI/CD).
- Understand Cloud Computing concepts, service models, and deployment models.
- Gain foundational knowledge of Generative Artificial Intelligence and its real-world applications.
