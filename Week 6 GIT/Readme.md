# 📂 Week 6 – Git & GitHub (CI/CD Fundamentals)

## 📖 Overview

This repository contains the **Week 6 Git Hands-on Exercises** completed as part of the **Cognizant Digital Nurture 5.0 – Java FSE Deep Skilling Program**.

The objective of this week was to gain practical experience with Git version control, repository management, branching, merge conflict resolution, and remote repository operations using GitHub.

---

# 🎯 Learning Objectives

Throughout this week, the following Git concepts were practiced:

- Git Installation and Configuration
- Local Repository Initialization
- Creating and Managing Git Repositories
- Tracking Files
- Git Ignore Configuration
- Branch Creation and Management
- Branch Merging
- Merge Conflict Resolution
- Connecting Local Repository with GitHub
- Git Push and Git Pull Operations

---

# 📁 Hands-on Exercises

## ✅ HO1 – Git Configuration

### Objective

Configure Git with global username and email, initialize a repository, create the first commit, and verify Git configuration.

### Concepts Covered

- Git Installation
- Global Configuration
- git config
- git init
- git add
- git commit
- git log

---

## ✅ HO2 – Git Ignore

### Objective

Learn how to exclude unnecessary files and folders from version control using `.gitignore`.

### Concepts Covered

- .gitignore
- Ignoring log files
- Ignoring folders
- Working Tree
- Git Tracking

---

## ✅ HO3 – Branching and Merging

### Objective

Create branches, switch between branches, commit changes independently, merge branches, and delete merged branches.

### Concepts Covered

- git branch
- git checkout
- git switch
- git merge
- git branch -d
- git diff
- Branch History

---

## ✅ HO4 – Merge Conflict Resolution

### Objective

Simulate a merge conflict, manually resolve the conflict, and complete the merge successfully.

### Concepts Covered

- Merge Conflict
- Conflict Resolution
- Manual Editing
- Commit after Conflict Resolution
- Git History

---

## ✅ HO5 – Git Push and Git Pull

### Objective

Connect a local Git repository to GitHub and synchronize changes between local and remote repositories.

### Concepts Covered

- Remote Repository
- git remote add origin
- git push
- git pull
- GitHub Repository Synchronization
